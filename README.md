# 컷 배치 편집기

영상 속 캐릭터를 조금 옮길 때마다 AI에게 좌표를 바꿔 달라고 요청했습니다. 화면에서 직접 위치를 잡고 싶어 제작용 편집기에 3D 이동 핸들을 넣었고, 그 조작을 기본 도형으로 체험할 수 있게 구성했습니다.

**[브라우저에서 편집기 열기](https://wwk1tten.github.io/shot-placement-editor/)**

1. 컷 A의 정육면체에 달린 화살표를 끌어 보세요. 오른쪽 좌표도 함께 바뀝니다.
2. 컷 B로 바꿔 구의 위치를 숫자로 입력해 보세요.
3. 컷 A로 돌아가거나 새로고침하면 각 컷의 위치를 다시 볼 수 있습니다. ‘이 컷 위치 초기화’는 선택한 컷에만 적용됩니다.

## 원래 제작 도구와 이 데모

원래 도구는 Remotion Studio에서 Three.js의 TransformControls를 캐릭터 그룹에 붙이고 조작이 끝날 때 컷별 배치를 파일에 기록합니다. 공개 데모에서는 정육면체와 구를 사용하고 위치를 브라우저의 로컬 저장소에 기록합니다. 편집 방식을 제안하고 실제 영상에서 구도를 결정한 것은 이지원이며, 제작용 편집기와 공개 데모 코드 작성에는 AI를 활용했습니다.

[편집기 소스](src/editor.js)에는 도형에 이동 핸들을 붙이는 부분, 좌표 입력과 화면을 동기화하는 부분, 컷별 위치를 저장하는 부분이 들어 있습니다.

## 로컬 실행

배포용 파일이 포함되어 있습니다. 저장소를 내려받은 뒤 루트에서 `python3 -m http.server 8000`을 실행하고 브라우저로 `http://localhost:8000`을 여세요. WebGL 2가 필요합니다.

소스를 수정한 뒤에는 `npm install`, `npm run build` 순서로 다시 빌드하세요. 번들에 포함된 Three.js의 저작권 고지는 [THREE-LICENSE.txt](THREE-LICENSE.txt)에 있습니다.
